# 面试复盘助手 (Interview Review Assistant)

## 项目介绍

**面试复盘助手**是一款基于AI的Web应用,通过分析真实面试录音,帮助应届生求职者进行科学化、系统化的面试复盘。

---

## 项目背景

应届生在求职期间通常需要经历约10场面试。当前,绝大多数求职者在面试结束后完全依赖记忆进行复盘,这种方式存在严重问题:

- **记忆快速衰减**: 面试结束后数小时内,具体问答细节已大幅遗忘,无法精准回顾
- **缺乏量化评估**: 求职者不清楚自己在哪些维度表现优秀、哪些维度存在不足,改进缺乏依据
- **无法纵向追踪**: 多场面试之间的共性弱点和高频考点无法被系统性发现
- **改进效率低下**: 即使意识到"答得不好",也不知道具体应该如何改进表达方式
-

### 核心功能

#### 1. 智能录音分析

- 支持上传面试录音(m4a/mp3/wav/aac格式,最大500MB)
- 自动语音转文字,准确区分面试官与候选人
- 结构化提取问答对,识别追问链路
- 低置信度片段智能标记,确保关键内容可追溯

#### 2. 深度质量评价

- 自动标注每个问题的考察意图(技术深度、项目经验、表达能力等)
- 评价回答质量,明确标注表现好的部分和需要改进的部分
- 针对每个问答提供具体的改进建议和优化回答示例
- 多维度评价体系,帮助求职者全面了解自己的表现

#### 3. 跨面试规律分析

- 识别多场面试中反复出现的共性弱点
- 统计高频考点和考察方向
- 追踪同一能力维度在不同面试中的表现变化趋势
- 可视化薄弱维度,推荐改进优先级

#### 4. 灵活数据组织

- 按公司维度组织,展示各轮次面试完整记录
- 按岗位标签筛选,便于对比不同方向的面试
- 时间线视图全景展示求职进度
- 支持同公司多轮面试的连续追踪

---


### 核心使用场景

1. **面试后即时上传**: 小王刚面完一场后端面试,掏出手机把30分钟录音上传到网站
2. **查看纪要和建议**: 几小时后打开电脑,阅读结构化纪要,查看每个回答的评价和改进示例
3. **多轮复盘**: 同一家公司二面前,回顾一面的改善点,重点准备薄弱项
4. **规律洞察**: 面了5家公司后,查看跨面试分析,发现自己在"项目复杂度表达"上总是丢分
